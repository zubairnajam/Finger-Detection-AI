      06 — Engineering

      Design decisions.

      A

      Position-invariant features

      Raw landmark coordinates encode where the hand is in the frame, so moving it off-centre or closer dropped accuracy to 62–83% and turned many 4s into 5s. Features are now wrist-relative, scale-normalised and include joint angles, with mirrored and jittered training copies. Webcam accuracy rose from 89.6% to 96.2%.

      B

      Custom inference engine

      keras.predict() spent tens of milliseconds per frame on dispatch overhead. The trained weights run as a NumPy forward pass in ~0.03 ms, and as a small JS engine in the browser. Parity tests check both.

      C

      Tested state machine

      Countdown logic lives in an I/O-free GestureController. A gesture must hold for 0.6 s to arm, then the countdown is locked until capture. Unit tests drive it with synthetic timestamps.

      D

      Temporal stabilisation

      An 8-frame majority vote (at least 4 agreeing frames and 55% mean confidence) turns noisy per-frame predictions into deliberate actions.

      E

      Reproducible metrics

      One command runs preprocessing, training, evaluation and web export. This page reads the resulting metrics.json, so it never drifts from the model.

      F

      Private by default

      Inference runs on-device on desktop and web. Frames are never uploaded, and photos stay in memory until you download them.
