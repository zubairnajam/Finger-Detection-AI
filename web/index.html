      Engineering

      Built like production software

      Design decisions behind the system.

      ⚡

      Custom inference engine

      Profiling showed keras.predict() spent ~75 ms per frame on dispatch overhead. The trained weights now run as a NumPy forward pass in 0.03 ms, and as a 60-line JS engine in the browser. Parity tests check both against Keras.

      🧪

      Tested state machine

      The countdown/capture logic is a pure, I/O-free GestureController. Unit tests cover arming, cancelling, re-arming, cooldown and burst-shot prevention with synthetic timestamps.

      🔄

      Temporal stabilisation

      An 8-frame majority vote (≥ 4 agreeing frames, ≥ 55% mean confidence) turns noisy per-frame predictions into deliberate actions. The jitter benchmark above measures its effect.

      📊

      Reproducible metrics

      One command runs collection → preprocessing → training → evaluation → benchmarks → web export. This page reads the resulting metrics.json, so the site never drifts from the model.

      🔒

      Privacy by design

      Inference runs entirely on-device, on both desktop and web. Webcam frames are never uploaded, and photos stay in memory until you download them.

      🛡️

      Graceful degradation

      GPU→CPU fallback for the hand tracker, a geometric finger-counting fallback if the model can't load, and clear camera-permission errors.
