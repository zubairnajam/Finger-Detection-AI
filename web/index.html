Approach

Technology stack and design decisions behind the system.

🖐️

Hand Detection

MediaPipe Hand Landmarker (float16) detects 21 3D keypoints per hand with confidence thresholds lowered to 0.35 for robust detection across lighting.

📐

Feature Extraction

21 landmarks × 3 coordinates (x, y, z) = 63-dimensional feature vector. No hand-crafted geometric features — the network learns directly from raw coordinates.

🧠

Neural Network

4-layer MLP (128→64→32→6) trained with Adam optimiser, early stopping, class weighting, and ReduceLROnPlateau. Only ~260 KB.

🔄

Stabilisation

8-frame rolling-window majority vote with ≥4 agreement and ≥55% confidence. Smooths out per-frame noise for reliable gesture detection.
